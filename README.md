# Quant SMC OB / FVG / BOS

A public TradingView Pine Script FVG / Smart Money Concepts project published by Jayadev Rana for traders and developers studying fair value gaps, order blocks, liquidity, and market structure.

## Overview

This repository contains a Pine Script source file saved as `pinescript_quant_smc_ob_fvg_bos_indicator.txt` so it opens easily on GitHub and can be copied into TradingView.

The script focuses on Fair Value Gap / FVG, Order Blocks, Break of Structure, imbalance, RSI, alerts. It is useful for FVG research, Smart Money Concepts chart review, TradingView indicator development, alerts, and technical-analysis education.

For custom TradingView Pine Script development, visit https://jayadevrana.com.

Quant SMC OB / FVG / BOS gives traders a focused workflow around fair value gaps and market-structure concepts. Depending on the source logic, it may highlight imbalance zones, order blocks, BOS/CHoCH structure, liquidity areas, trend context, or alert-ready conditions.

## How to Use in TradingView

1. Open TradingView.
2. Go to Pine Editor.
3. Copy the code from `pinescript_quant_smc_ob_fvg_bos_indicator.txt`.
4. Paste it into Pine Editor.
5. Save the script.
6. Add it to your chart.
7. Configure inputs and visual settings.
8. If alert conditions are available, create alerts from TradingView's alert dialog.
